# 📌 Overview

This project is a **low-cost Smart Radar & Intrusion Detection System** built using the **ESP32 ecosystem**.

The system scans surroundings using an ultrasonic/radar sensor mounted on a servo motor and visualizes detections in real-time like a mini military radar system.

It was designed as a **2nd Year Microcontroller & Microprocessor Project** focusing on:

- Embedded Systems
- Sensor Fusion
- Real-time Monitoring
- IoT Communication
- Smart Security Solutions

---

# 🎯 Features

✅ Real-time radar scanning  
✅ Servo-based 180° sweep  
✅ Ultrasonic object detection  
✅ ESP32-powered processing  
✅ Radar visualization on PC  
✅ Sound-triggered intrusion logic  
✅ Low-cost implementation  
✅ Expandable to IoT surveillance systems
